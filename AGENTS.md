# AISDK

This repository owns independently installable Vercel AI SDK media tool packages. Source of truth for service behavior remains AceDataCloud/MCPs; never duplicate workers or add fallback/pricing here. `shared/connector.js` is copied into each package by `npm run build`; edit the source, not generated dist. Run build, Node tests, TypeScript checks, package-content verification. Read-only discovery never calls tools/call. No paid generations in CI. Each tool package must keep default read-only mode, per-call application approval and persistent original task IDs. Keep README Key onboarding and attribution links current; do not print credentials. Use Ace Data Cloud Dev bot PRs and inspect remote PR OPEN before follow-up pushes. No automated merge or production deploy.
